# House Price Prediction

## Project Description
This project predicts house prices using Machine Learning.

## Algorithm
- Linear Regression

## Features
- Area
- Number of Bedrooms
- Number of Bathrooms

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Model Result
R2 Score: 0.9993

## Prediction Example
For a house with:
- Area: 1600 sq.ft
- Bedrooms: 3
- Bathrooms: 2

Predicted Price: ₹5,809,414
